# UI & UX Design

## Overview
This skill governs the creation and implementation of the game's interface, ensuring a cohesive "Ink-Wash" + "Cyber-Neon" aesthetic. It prioritizes data-driven asset management, AI-assisted asset creation, and seamless integration with Naninovel's engine.

## Key Concepts
- **Data-Driven UI**: Uncoupling logic from assets using `UIAssetDatabase`.
- **AI-Assisted Workflow**: Generating UI slices with AI and automating their import/categorization.
- **Naninovel Integration**: Using custom commands (`@changeUI`) to control Unity UI from narrative scripts.
- **Vector Graphics**: Leveraging SVG and Shapes for resolution-independent UI elements.
