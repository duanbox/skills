# Skill: Verify

Trigger: When user asks to "Verify Code", "Check Errors", or "Fix Compilation".

## Goal

Check the codebase for compilation errors using the project's solution file.

## Steps

1. **Locate Solution**:
   - Find the `.sln` file in the project root (e.g., `EndGods.sln`).

2. **Run Build**:
   - Run command: `dotnet build [SolutionFile]`.
   - *Note*: This checks for C# syntax and reference errors. It requires the `.sln` file to be generated by Unity (Preferences -> External Tools -> Regenerate project files).

3. **Analyze Output**:
   - **Success**: Code is valid.
   - **Failure**:
     - Identify error locations (File, Line) and Descriptions.
     - Quote the error message clearly.

4. **Action**:
   - If simple (missing semicolon, typo): **Fix immediately**.
   - If complex (logic/architecture): **Propose a plan**.

## Command Reference

```bash
# General
dotnet build

# Specific Solution
dotnet build EndGods.sln
```
