# Skill: Story Weaver

Trigger: When user asks to "Write Dialogue" or "Generate Scene".

## Context

- World: Setting Sun of Gods (Post-Apoc + Cultivation).
- Tone: Ink Wash Wasteland, Desolate but Neon.

## Rules

1. **Reference Check**:
   - Check `System Settings.docx` for power levels.
   - Check `Forces & Characters.docx` for character tone.

2. **Writing Style**:
   - Use Naninovel script syntax (`# Character`, `@print`).
   - Use "Dao-Tech" terminology (Spirit Orbs, not Batteries).

3. **Format**:
   - Output valid `.nani` syntax.
   - Use `IsKey` for localization placeholders instead of raw text if possible.
